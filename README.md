# CONTINUUM

### A Modular Performance Ecosystem

**Created by Stefano Pollina**

Continuum is an evolving collection of browser-based musical instruments, synthesizers, rhythm engines and performance environments designed around accessibility, experimentation and interoperability.

Each instrument can operate independently, while the wider architecture explores how synthesis, rhythm, sequencing, mixing, effects and external hardware can become interconnected components of a larger musical performance system.

## Explore Continuum

The Continuum landing page brings together 11 instruments, with embedded interface previews, descriptions, technical highlights and links to their individual GitHub repositories.

### Instrument Collection

1. **Continuum Mosaic** — An integrated modular synthesis, rhythm, sequencing and performance environment.
2. **Continuum Nexus** — Flexible oscillator routing and extended 128-step sequencing.
3. **Continuum Obsidian** — Expressive eight-voice polyphonic synthesis.
4. **Parallel Hybrid Architecture** — Eight synthesis families, eight banks and 64 configurable engine slots.
5. **Performance Synthesis Module** — Experimental live performance, capture and musical transformation.
6. **Azure Matrix** — Multi-oscillator synthesis with matrix-oriented sound shaping.
7. **Continuum Ebony** — Synthesised percussion, modulation patching and evolving rhythmic structures.
8. **Continuum Silver** — Eight-voice drum synthesis and pattern sequencing.
9. **Continuum Blue** — Polyphonic digital synthesis with multiple oscillator architectures.
10. **Mosaic Rhythm Engine** — Layered breakbeats, percussion synthesis and live rhythm performance.
11. **Continuum Rhodium** — Developing multi-layer synthesis architecture with extensive modulation and sequencing.

## The Continuum Architecture

Continuum is designed to grow beyond a collection of standalone instruments.

The longer-term vision is a distributed, modular musical environment in which individual instruments and processing systems can be connected through MIDI, audio routing and shared performance workflows.

A synthesizer can connect to a sequencer. A rhythm engine can provide the foundation for a live arrangement. External instruments, controllers and audio sources can contribute to the same performance system.

Rather than requiring every musical function to exist inside one enormous application, Continuum explores an ecosystem of specialised instruments that can develop independently and ultimately work together.

**A modular musical environment whose scale and structure are determined by the person playing it.**

## Technology and Development

Continuum instruments explore browser-based audio synthesis, interactive interfaces, sequencing, modulation and performance control.

The project uses web technologies including HTML, CSS, JavaScript and, where implemented, Web Audio and Web MIDI.

The gallery itself is a standalone HTML page designed to present the instruments and provide direct access to their individual projects.

The instruments are at different stages of development. Some are playable experimental builds, while others remain under active refinement.

## Project Direction

Ongoing areas of exploration include:

- Standalone synthesis and percussion instruments
- Modular signal routing and interconnected performance systems
- MIDI controller and external hardware integration
- Live sequencing, rhythm manipulation and musical improvisation
- Accessible browser-based musical environments
- Future integration with digital audio workstations

## Running the Gallery

The landing page is a standalone HTML document.

To use it locally, open `index.html` in a modern web browser.

To publish it through GitHub Pages, enable Pages for the repository and select the branch containing `index.html`.

The embedded instrument previews require access to their separately hosted pages. Audio and MIDI functionality may depend on browser support, device permissions and user interaction.
